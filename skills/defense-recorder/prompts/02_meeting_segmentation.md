# 答辩会切分

将完整答辩会切分为多个答辩人场次。

## 输入

- 带时间戳的转写文本
- 答辩人名单或答辩顺序表，如有
- 从幻灯片、论文、摘要或口头陈述中识别出的论文题目

## 边界证据

优先使用明确的主持人或流程语句：

- `下面请第一位同学进行汇报`
- `请张三同学开始答辩`
- `下面有请张三同学`
- `我的论文题目是...`
- `我汇报的题目是...`
- `感谢张三同学的汇报`
- `下面进入专家提问环节`
- `请各位老师提问`
- `张三同学答辩到此结束`
- `下面请下一位同学`

如果没有明确语句，则根据模式推断：较长的答辩人陈述、评委问答、过渡语、下一位答辩人的较长陈述。

## 规则

- 优先使用答辩顺序表或官方名单，不要先依赖音频猜测。
- 如果无法确认姓名，使用 `未知答辩人 N`。
- 不要编造姓名或论文题目。
- 不要把全场统一的说话人 ID 直接绑定为某个答辩人。
- 起止边界不明确时，标记为 `confidence: low`。

## 输出

```json
[
  {
    "candidate_order": 1,
    "candidate_name": "张三",
    "thesis_title": "xxx",
    "start_time": "00:05:12",
    "end_time": "00:38:45",
    "boundary_evidence": [
      "请张三同学开始答辩",
      "张三同学答辩到此结束"
    ],
    "confidence": "high"
  }
]
```
