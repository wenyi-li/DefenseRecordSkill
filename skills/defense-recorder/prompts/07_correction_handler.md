# 修正处理

当用户在答辩记录生成后修正答辩人姓名、场次归属、术语修正、问答归属或回答内容时，使用本规则。

## 规则

- 只修改受影响的部分。
- 除非修正会改变整体结构，否则不要重写完整记录。
- 保留现有 Markdown 结构。
- 必要时更新术语修正说明和低置信度说明。
- 如果修正改变了答辩人身份，只更新该答辩人的标题、元数据和相关引用。
- 如果某条问答属于另一位答辩人，只移动该条问答，并在需要时调整两位答辩人的低置信度说明。
- 如果用户修正某条回答，只修改该条回答；除非该修正也影响相邻问答或低置信度说明。

## 输出

返回更新后的受影响部分；如果处于可写文件环境，则直接更新 `defense_records.md`。
